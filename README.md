# Brew & Bean Café ☕

A complete, fully responsive single-page website for a fictional coffee shop, **Brew & Bean Café** — built with plain HTML5, CSS3, and vanilla JavaScript, and designed as a clean, professional student web development portfolio project.

## Description

Brew & Bean Café is a warm, modern one-page website that showcases a coffee shop's story, menu, specialties, and contact details. It includes an interactive, filterable menu, a validated contact form, smooth scrolling navigation with a mobile hamburger menu, and a scroll-to-top button — all built without any frameworks, libraries, or backend.

## Features

- 📌 Sticky, responsive navigation bar with smooth scrolling
- 📱 Mobile hamburger menu that opens/closes and auto-closes after a link is selected
- 🖼️ Hero section with a strong headline and call-to-action buttons
- 📖 About section with story content and animated-free statistic highlights
- ☕ Filterable menu (All / Coffee / Tea / Pastries / Desserts) with 12 items, powered by vanilla JavaScript — no page reloads
- ⭐ "Our Specialties" section highlighting three popular drinks
- 🧡 "Why Choose Us" feature grid
- 💬 Customer testimonials section
- 📞 Two-column contact section with a fully validated contact form (required fields, email format check, minimum message length) and a success message on submission
- ⬆️ Scroll-to-top button that appears after scrolling
- 🧭 Active navigation link highlighting based on scroll position
- ♿ Semantic HTML5, labeled form fields, meaningful alt text, and keyboard-accessible controls
- 📐 Fully responsive from 1440px desktops down to 360px small mobile screens

## Technologies Used

- **HTML5** — semantic markup
- **CSS3** — Flexbox, CSS Grid, custom properties, media queries
- **Vanilla JavaScript (ES6)** — no frameworks or libraries
- **Google Fonts** — Fraunces (headings) & Nunito Sans (body)
- **Font Awesome** — icons

No React, Vue, Angular, Bootstrap, Tailwind, backend, database, authentication, or payment systems are used.
